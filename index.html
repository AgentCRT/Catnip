Features

Everything Roblox
should have built in.

The things you actually want, without the bloat you don't.

⚑

FastFlags Editor

Unhidden access to Roblox's internal feature flags. Tweak rendering, performance, and behaviour directly.

◈

Discord Rich Presence

Shows your current game, server info, and playtime on your Discord profile automatically.

◧

Mod Support

Drop in custom sounds, cursors, textures, and assets. Catnip handles applying them on every update.

◉

Custom Themes

Multiple built-in bootstrapper styles, including a classic look and a modern dark UI.

↻

Auto-Updates

Catnip keeps itself and Roblox up to date silently. No manual reinstalls when Roblox pushes a patch.

⬡

Studio Support

Fully supports Roblox Studio alongside the player. One install covers both.

Built in the open.

Catnip is fully open source. Read the code, report issues, or contribute — everything is on GitHub.
